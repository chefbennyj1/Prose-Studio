AI Settings

Gemini powers Critique, Line edits and the opinion on overused words. They stay hidden from the rail until you switch this on. Spelling, the mechanics scan, the overused-word counting and the narrator run on this machine, free, whether this is on or off.

What gets sent to Google

This is the price of the extra help. Switch it on and, when you run one of these, your writing goes to Google's servers to be read by their model:

  • Critique — sends the whole chapter you have open. The critic needs the shape of the thing to say anything useful about it, so there is no smaller version of this.
  • Line edits — sends the whole chapter as well. It is looking for repetition across paragraphs, which cannot be found in a chapter cut into pieces.
  • Overused words — sends counts and a few example sentences, at most six per word. Not the manuscript. The counting itself is done here and never leaves.

Everything else in the editor stays on this machine. With this switched off, nothing in the Prose Engine talks to Google at all — an API key on its own does not enable it.

Adds Critique, Line edits and the overused-word opinion to the Review menu in the rail. Switching it off removes them again and stops anything being sent.

Manuscript Backup

Push a story to GitHub with one button, from beside Save in the editor. You get version history and an off-site copy, and you can read back any earlier draft. Each story gets its own repository, and a story with none set is simply not backed up. New repositories are always private. Nothing to install — Git is not needed on this machine.

Create token

“Create token” opens GitHub with the right permission already ticked. Set an expiry you are happy with, generate it, and paste it here.
